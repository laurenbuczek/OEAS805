how do you put a line on a graph in python that is a dotted line where y = 0.90, like a htreshold line

In Matplotlib, use plt.axhline() (or ax.axhline() when using subplots) to draw a horizontal threshold line across the plot. Pass y=0.90, linestyle='--' (or ':' for dots), and specify a color.

Functional Example (plt interface)
Python
import matplotlib.pyplot as plt

# Sample data
x = [1, 2, 3, 4, 5]
y = [0.82, 0.88, 0.91, 0.95, 0.94]

plt.plot(x, y, marker='o', label='Performance')

# Add the dotted horizontal threshold line at y = 0.90
plt.axhline(y=0.90, color='r', linestyle=':', label='Threshold (0.90)')

plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.title('Performance vs Threshold')
plt.legend()
plt.show()
Object-Oriented Example (ax interface)
Python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()

ax.plot([1, 2, 3, 4, 5], [0.82, 0.88, 0.91, 0.95, 0.94])

# Add threshold line to specific axes instance
ax.axhline(y=0.90, color='red', linestyle='--', linewidth=1.5, label='Threshold')

ax.legend()
plt.show()
Key Parameters for axhline
y: The y-axis value where the line crosses (e.g., 0.90).

linestyle: Set to ':' for dotted or '--' for dashed.

color: Standard color names ('red', 'black') or hex codes ('#ff0000').

linewidth: Adjusts line thickness (default is 1.5).

xmin / xmax: (Optional) Controls where the line starts and ends as a fraction between 0 (left) and 1 (right). Defaults to 0 and 1 (spans the entire plot).

How do I do this with new "unknown wine" data that is important as a csv?

To predict classes for new "unknown wine" data loaded from a CSV file, use pandas.read_csv() to load the data, apply your pre-fitted scaler.transform(), pass the scaled features to mlp.predict(), and map the numeric predictions back to the class names.

Here is the complete step-by-step workflow:

Python
import pandas as pd

# 1. Load the new wine CSV file
# Ensure the CSV contains only the feature columns in the exact order as training
new_wine_df = pd.read_csv('unknown_wine_data.csv')

# 2. Scale the new data using the ALREADY fitted scaler
# Do NOT call fit_transform() here—only transform()
x_new_scaled = scaler.transform(new_wine_df)

# 3. Make predictions using the trained MLP classifier
y_predict = mlp.predict(x_new_scaled)

# 4. Map numeric predictions to class names
# Adjust class names dictionary to match your wine dataset classes
wine_classes = {0: 'Class_0', 1: 'Class_1', 2: 'Class_2'}
predicted_names = [wine_classes[pred] for pred in y_predict]

# 5. Add predictions directly back into your dataframe to review results
new_wine_df['Predicted_Class_Numeric'] = y_predict
new_wine_df['Predicted_Class_Name'] = predicted_names

print(new_wine_df)
Key Rules for CSV Prediction
Do not re-fit the scaler: Use scaler.transform(new_wine_df) rather than fit_transform(). Re-fitting will overwrite the feature scaling rules learned from your training set and skew predictions.

Match feature order: Ensure the columns in unknown_wine_data.csv match the exact order and count of the features used during mlp.fit().

Exclude target/label columns: If your CSV already contains an ID or actual label column, separate it first: x_new = new_wine_df.drop(columns=['id', 'target']).

how do I delete a column in my data in python but .copy()

To delete a column while preserving your original DataFrame using .copy(), explicitly call .copy() when assigning the modified DataFrame or before running .drop().

Here are the two ways to do it in Pandas:

Method 1: Drop the column on a copied DataFrame (Recommended)
Make a fresh copy of your DataFrame first, then drop the column from the new copy. This leaves your original DataFrame (df) completely untouched.

Python
import pandas as pd

# Create a clean copy of the original DataFrame
df_cleaned = df.copy()

# Drop the column from the new DataFrame
df_cleaned = df_cleaned.drop(columns=['column_to_delete'])
Method 2: One-liner using .copy()
You can chain .drop() and .copy() together in a single line:

Python
# Create a new DataFrame with the column removed and copied in memory
df_cleaned = df.drop(columns=['column_name']).copy()
Method 3: Keep specific columns instead of dropping
If you have many columns and only want to keep the 13 feature columns (for example, from your wine dataset), slice the columns and call .copy():

Python
# Keep only the first 13 columns as a new DataFrame copy
X_new = df.iloc[:, :13].copy()
Why use .copy() here?
Using .copy() creates an independent dataset in memory. This prevents Pandas from throwing a SettingWithCopyWarning when you modify df_cleaned later in your pipeline.

from sklearn.datasets import load_wine
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
import numpy as np
import pandas as pd

# Load the wine dataset
wine = load_wine()
X, y = wine.data, wine.target
target_names = wine.target_names

# Split into train/test sets
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Train a probabilistic classifier
clf = LogisticRegression(max_iter=1000)
clf.fit(X_train, y_train)

# Get probabilities for each class
probs = clf.predict_proba(X_test)

# Display results
print("Class names:", target_names)
print("\nSample probabilities for each test wine:")
for i, wine in enumerate(X_test):
    print(f"Unknown wine {i+1}:")
    for j, class_name in enumerate(target_names):
        print(f"  Class {class_name}: {probs[i, j]:.4f}")
