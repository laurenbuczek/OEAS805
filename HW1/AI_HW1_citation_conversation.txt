If Windows or PowerShell is blocking you from creating a text file, it usually comes down to File Explorer settings, folder permissions, or OneDrive interfering.

Here are the 3 quick fixes to get your file created right now:

1. Create it using echo (Bypasses PowerShell permissions)
PowerShell's New-Item can sometimes fail if system execution policies are strict. Try this simple command instead:

PowerShell
echo "Hello World" > hello.txt
Then run ls to verify it appears.

2. Fix File Explorer "Hide Extensions" (Most Common Issue)
If you tried creating it via File Explorer right-clicking (New > Text Document), Windows hides file extensions by default. You likely named it hello.txt, but Windows secretly named it hello.txt.txt.

Open File Explorer and navigate to your git_exercise folder.

Click View at the top menu.

Select Show > check File name extensions.

If you see hello.txt.txt, rename it to just hello.txt.

3. Move out of OneDrive (If sync is locked)
If your OEAS805 folder is synced with Microsoft OneDrive, OneDrive occasionally locks folders and prevents new files from being created via terminal.

Check your current path:

If your path in File Explorer shows C:\Users\laure\OneDrive\..., open Notepad normally, type your content, and use Save As to manually pick C:\Users\laure\OEAS805\git_exercise\hello.txt, ensuring Save as type is set to All Files (.).

If the file exists but you can't type into it, open it directly from your terminal using Windows Notepad:

PowerShell
notepad hello.txt
This will launch a Notepad window. Type your text, press Ctrl + S to save, and close Notepad.

If Notepad refuses to save or says "Access Denied":

Close programs using the file: Make sure another program (like VS Code, Excel, or Word) isn't locking the file open.

Force write text directly from PowerShell: Skip text editors entirely and force content into the file by running:

PowerShell
Set-Content -Path .\hello.txt -Value "Hello Git"
Once you've done either option, verify it worked and stage it:

PowerShell
Get-Content hello.txt
git add hello.txt

The command git remote set-url is used to update the URL of a remote repository that already exists. Since Git is telling you error: No such remote 'origin', it means no remote named origin has been added to this local repository yet.

To fix this, add the remote instead of updating it:

PowerShell
git remote add origin git@github.com:laurenbuczek/OEAS805.git
Verify the fix
After running that command, verify that the remote was successfully added:

PowerShell
git remote -v

PowerShell
